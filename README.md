# gnosis
OCR and LVLM pipeline evaluation project maintained by the KTH AI Society development team. 

## Goals & Purpose
To build and evaluate Visual Language Models (VLMs) & Optical Character Recognition (OCR) implementations for data extraction from images of graphs & plots, particularly in the petroleum & gas industry.
